# Gangnam Region Policy

`서울 강남구`는 재활용척척의 1차 지역 보강 대상이다. 런타임 데이터는 `src/data/region-policies.json`의 `gangnam_gu` 항목을 기준으로 한다.

## Why This Exists

`region_review_needed` 품목은 전국 공통 판단만으로는 사용자에게 충분하지 않은 경우다.

- 폐건전지: 전용 수거함 배출은 공통 기준이지만, 실제 수거함 위치는 지역별로 다르다.
- 종이컵, 투명페트병, 비닐: 분리배출 방식은 공통 기준이 있지만 강남구는 요일제 안내가 있다.
- 의자, 매트리스, 이불: 대형폐기물 신고 대상과 수수료가 지역별로 다르다.
- 요가매트: 종량제봉투에 담기면 일반쓰레기지만, 큰 매트는 대형폐기물 신고 대상과 유사 품목 수수료가 지역별로 다르다.
- 폐의약품, 폐식용유, 의류수거함: 수거함 위치정보가 지역별로 다르다.
- 깨진 유리: 지역에 따라 불연성 종량제 마대, PP봉투, 소량 종량제봉투 기준이 달라질 수 있다.
- 닭뼈, 조개껍데기, 달걀껍데기, 과일씨, 생선뼈, 티백, 양파껍질: 품목사전상 일반쓰레기지만, 사용자가 입력한 지역의 음식물류 제외 품목 안내를 함께 보여주면 혼동을 줄일 수 있다.
- 곰팡이 핀 빵: 품목사전상 상한 음식은 음식물류폐기물이지만, 강남구의 전용 종량제봉투/RFID 배출 방식을 함께 보여주면 실제 배출까지 이어지기 쉽다.

## Gangnam Defaults

- 일반쓰레기: 월요일~금요일 20:00~익일 05:00, 내 집 앞 또는 내 점포 앞
- 재활용품: 20:00~익일 05:00, 집 앞 또는 잘 보이는 곳
- 목요일: 비닐·투명페트병만 배출
- 월·화·수·금·일요일: 비닐·투명페트병 이외 재활용품 배출
- 음식물쓰레기 제외 품목: 동물뼈, 조개껍데기, 한약재 찌꺼기, 달걀껍데기, 게 껍질, 밤·호두껍질, 핵과류 씨, 생선뼈, 파 뿌리, 양파껍질, 티백 등은 일반 종량제봉투 배출
- 대형생활폐기물: 배출 3일 전까지 사전 신청, 접수증 또는 접수번호 부착
- 대형생활폐기물 수수료: `src/data/bulky-waste-fees.json`에 분리 저장하며, 현재 coverage 10개 itemId인 의자, 매트리스, 이불, 거울, 리빙박스·플라스틱 수납함, 요가매트, 빨래건조대, 화분, 장난감, 인형 수수료 후보를 반영한다.

## Bulky Waste Fee Linkage

- 강남구 수수료 구조화 데이터는 `src/data/bulky-waste-fees.json`의 `regionId: gangnam_gu` 스케줄에만 있다.
- 런타임은 `region-policies.json`의 지역 ID와 수수료 스케줄의 `regionId`를 맞춰 의자, 매트리스, 이불, 거울, 리빙박스·플라스틱 수납함, 요가매트, 빨래건조대, 화분, 장난감, 인형 안내에 수수료 후보를 붙인다.
- 공식 수수료 출처는 강남구 자원순환 종합포털 `대형생활폐기물 안내`이며, 신청 URL은 현재 휴대폰 인증 신청 화면인 `USEBIWA02010000.do` 경로를 사용한다.
- 2026-07-02 재확인 결과 요가매트 유사 품목인 `돗자리(대자리/놀이매트)`는 `1㎡당 1,000원`으로 표기되어 있어 데이터 표현을 이에 맞춘다.

## Remaining Work

- 강남구 수거함 위치 데이터는 현재 위치정보 페이지 URL 기반 안내다. 아이스팩처럼 공식 위치정보 메뉴에 항목이 없는 품목은 정확한 주소를 답하지 않고 운영 여부 확인 안내로 처리한다. 좌표/주소를 별도 데이터로 구조화하려면 공식 위치 원천의 추가 수집이 필요하다.
- 대형폐기물 수수료는 Top 50 관련 일부 품목을 별도 데이터로 분리했다. 품목 전체 수수료표를 가져오려면 공식 페이지의 전체 수수료 행을 itemId 매핑 기준과 함께 별도 import 스크립트로 관리하는 편이 좋다.
- 음식물쓰레기 제외 품목 중 동물뼈, 조개껍데기, 한약재 찌꺼기, 달걀껍데기, 게 껍질, 밤·호두껍질, 파 뿌리는 강남구청 안내로 교차 확인했다. 후속 첨부 감사에서 `핵과류 씨(복숭아 씨 등)`, `생선뼈`, `티백`, `양파껍질`은 공식 PDF 직접 근거를 확인해 데이터에 반영했다. `옥수수대·옥수수껍질`은 강남 직접 근거가 없어 계속 보류한다.
