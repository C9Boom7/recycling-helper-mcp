# Source Coverage

Top 50 데이터와 사용자 질문에서 승격한 확장 품목은 공식 출처를 기준으로 다음 검수 상태를 사용한다.

## Review Status Summary

- `verified`: 전국 공통 분리배출 기준으로 우선 답변 가능한 품목
- `region_review_needed`: 기본 판단은 있으나 수거함 위치, 배출일, 신고 방식, 수수료 등 지역 기준 확인이 필요한 품목
- `needs_source`: 공식 단독 품목 근거는 없지만 보조 근거 또는 재활용척척 예외 배출 정책으로 답변을 제공하며, 품목사전 원문 또는 지자체 원문 보강이 필요한 품목
