# Source Gap Policy

공식 품목사전이나 지자체 원문에서 단독 품목 기준을 찾지 못한 항목은 `needs_source`로 유지하되, 답변을 비워두지 않는다. 제품 정책상 명확히 재활용품·음식물쓰레기 예외로 보는 품목은 일반쓰레기/종량제봉투 배출로 고정 안내한다.

## 적용 기준

- 생활폐기물 분리배출 누리집 품목사전에서 단독 항목이 확인되지 않는다.
- 중앙정부, 공공기관, 지자체 페이지에서도 같은 품목명으로 직접 배출 기준을 확인하지 못했다.
- 다만 재질, 오염, 위생, 파손 등 유사 공식 근거와 서비스 예외 정책을 통해 안전한 예외 판단이 가능하다.

## 답변 원칙

- 재활용 가능성이 불명확한 오염·위생·소형 잔재물은 재활용품으로 단정하지 않는다.
- 하수구, 변기, 음식물쓰레기, 재활용품 혼합처럼 피해가 큰 오답을 먼저 막는다.
- `sources`에는 직접 근거와 보조 근거를 구분해 저장한다.
- 서비스 예외 정책으로 결론을 고정한 경우 `sources`에 `재활용척척 예외 배출 정책` manual review 항목을 남긴다.
- `review.notes`에는 공식 단독 근거가 없다는 사실과 검색일을 남긴다.
- 단독 공식 근거를 찾으면 `needs_source`에서 `verified` 또는 `region_review_needed`로 승격한다.
